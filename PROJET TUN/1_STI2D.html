Automatismes

Rappels de calcul et fonctions usuelles

Les automatismes permettent de manipuler rapidement les nombres et fonctions de base.

  • Puissances : an = a × a × ... × a, a0=1, a-n=1/an
  • Fractions : a/b + c/d = (ad+bc)/bd ; a/b × c/d = ac/bd ; simplification
  • Racines carrées : √(a×b)=√a×√b ; √(a/b)=√a/√b
  • Fonctions usuelles : f(x)=x², f(x)=√x, f(x)=1/x, f(x)=x³
  • Valeur absolue : |x|=x si x≥0, =-x sinon
Exemple : 2³ × 2-1 = 4

Exercice : Simplifier 5² × 5-3

5² × 5-3 = 5-1 = 1/5

Notion d’ensembles et logique

Vocabulaire et opérations sur les ensembles pour raisonner correctement.

  • Union : A∪B = éléments de A ou B
  • Intersection : A∩B = éléments de A et B
  • Complémentaire : A' = éléments n’appartenant pas à A
  • Inclusion : A⊂B → tous les éléments de A sont dans B
Exemple : A={1,2,3}, B={2,3,4} → A∩B={2,3}, A∪B={1,2,3,4}

Exercice : C={1,2,3,4}, D={3,4,5} → C∩D, C∪D, C\D ?

C∩D={3,4} ; C∪D={1,2,3,4,5} ; C\D={1,2}

Analyse (Dérivation et Courbes)

Dérivation des fonctions

Permet d’étudier les variations et de calculer les tangentes.

  • Règle générale : (xⁿ)' = n xⁿ⁻¹
  • Dérivées usuelles : const→0 ; x→1 ; x²→2x ; x³→3x² ; 1/x→-1/x² ; √x→1/(2√x)
  • Opérations : (u+v)'=u'+v' ; (uv)'=u'v+uv' ; (u/v)'=(u'v-uv')/v²
Ex : f(x)=x³-2x → f'(x)=3x²-2

Exercice : Dériver g(x)=x⁴-3x²+5

g'(x)=4x³-6x

Étude de fonctions et tableaux de variation

Utiliser la dérivée pour déterminer croissance, décroissance et extremums.

  • Calculer f'(x) puis résoudre f'(x)=0 → points critiques
  • Étudier le signe de f' pour déterminer variation
  • Identifier min et max, tracer tableau de variation
Ex : f(x)=x³-3x → f'(x)=3(x-1)(x+1) → extremums en x=-1 et x=1

Exercice : Étudier f(x)=x³-6x²+9x

f'(x)=3(x-1)(x-3) → extremums en x=1 et x=3

Algorithmique & Programmation

Algorithmes de calcul et conditions

Introduction aux pseudocodes, boucles et conditions.

  • Variables, affectation, lecture/écriture
  • Condition : SI … ALORS … SINON …
  • Boucles : POUR … FAIRE … ; TANT QUE … FAIRE …
Ex : calculer somme des n premiers nombres
DEBUT
somme ← 0
pour i de 1 à n
  somme ← somme + i
FIN POUR
AFFICHER somme
FIN

somme ← somme + x

Trigonométrie

Triangle rectangle

sin θ = opposé/hypothénuse ; cos θ = adjacent/hyp ; tan θ = sin θ / cos θ

Ex : triangle hyp=10, adj=6, opp=8 → sin θ=0.8 ; cos θ=0.6 ; tan θ≈1.33

Exercice : Calculer sin, cos, tan d’un triangle rectangle adj=5, opp=12, hyp=13

sin θ = 12/13 ; cos θ = 5/13 ; tan θ = 12/5

Nombres complexes

Forme algébrique

z = a + ib ; i²=-1

Ex : z₁=3+2i, z₂=1-i → z₁+z₂=4+i ; z₁×z₂=5+i

Exercice : Calculer (2+3i)+(1-2i) et (2+3i)×(1-2i)

Somme=3+i ; Produit=8-i

Forme trigonométrique

z = r(cos θ + i sin θ)

Ex : z=2(cos π/4 + i sin π/4)

Produit scalaire

Vecteurs et produit scalaire

u·v = |u||v|cos θ ; u·v = u₁v₁ + u₂v₂

Ex : u=(1,2), v=(3,4) → u·v=11

Exercice : Calculer produit scalaire de u=(2,3), v=(4,5)

u·v = 2*4 + 3*5 = 8+15=23
