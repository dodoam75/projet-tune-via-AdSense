Limites de Fonctions

Définition : La limite d'une fonction f(x) lorsque x tend vers une valeur a décrit la valeur vers laquelle f(x) se rapproche lorsque x s'approche de a (ou de l'infini).

Notations usuelles :

  • limx→a f(x) = L
  • limx→±∞ f(x) = L
Exemple : limx→∞ (1/x) = 0

Exercice : Calculer limx→∞ (3x²+2)/(2x²-5)

Corrigé : Diviser par x² : lim = 3/2

Dérivation

La dérivée d’une fonction mesure son taux de variation :

  • Si f'(x) > 0 → f est croissante
  • Si f'(x) < 0 → f est décroissante

Règles principales :

  • (xⁿ)' = n·xⁿ⁻¹
  • (eˣ)' = eˣ
  • (ln x)' = 1/x
Ex : f(x)=eˣ → f'(x)=eˣ

Exercice : Dériver f(x)=x³-5x²+4x

Corrigé : f'(x)=3x²-10x+4

Fonctions Exponentielles et Logarithmes

Fonction exponentielle : exp(x) = eˣ

Fonction logarithme népérien : ln(x), définie pour x>0

  • ln(ab) = ln(a)+ln(b)
  • ln(aⁿ) = n·ln(a)
Ex : ln(e)=1 ; e^(ln x) = x

Exercice : Calculer ln(e²) + ln(1/e)

Corrigé : ln(e²) + ln(1/e) = 2 - 1 = 1

Équations Différentielles

Équation différentielle simple : y' = ky → solution y = Ce^(kx)

Ex : y' = 3y → y = Ce^(3x)

Exercice : Résoudre y' - 2y = 0

Corrigé : y = Ce^(2x)

Suites Numériques

Une suite (un) est une liste de nombres indexée par n :

  • Suite arithmétique : un+1 = un + r
  • Suite géométrique : un+1 = q·un
Ex : un=3·2ⁿ → croissance exponentielle

Exercice : u₀=5, uₙ₊₁ = 2·uₙ. Calculer u₃

Corrigé : u₁=10, u₂=20, u₃=40

Probabilités et Statistiques

Notions avancées : loi binomiale, espérance, variance.

Ex : Pour X~B(n,p), espérance E(X)=np ; variance = np(1-p)

Exercice : X~B(5,0.3). Calculer P(X=2)

Corrigé : P(X=2) = C(5,2)·0.3²·0.7³ ≈ 0.26

Nombres Complexes

Un nombre complexe s'écrit z = a + ib, avec i²=-1.

Forme exponentielle : z = r·eiθ

Ex : eiπ = -1

Exercice : z₁ = 1+i, z₂ = 2-i → Calculer z₁+z₂

Corrigé : z₁+z₂ = (1+2) + (1-1)i = 3 + 0i = 3
